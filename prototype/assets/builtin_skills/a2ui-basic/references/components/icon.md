# Icon

```json
{
  "id": "status_icon",
  "component": "Icon",
  "icon": "check_circle",
  "color": "success",
  "size": 24
}
```

| Property | Type | Notes |
|---|---|---|
| `icon` | string | Icon name such as `check`, `warning`, `info`, `star`, `close`, `settings`, `search`, `send`, `refresh`, `menu` |
| `color` | string | `primary`, `secondary`, `error`, `success`, `warning`, or hex |
| `size` | number | Default `24` |

Use icons as decoration or status signals, not as the only carrier of important text.
