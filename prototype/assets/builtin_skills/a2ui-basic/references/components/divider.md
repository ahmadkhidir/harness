# Divider

```json
{
  "id": "separator",
  "component": "Divider",
  "thickness": 1,
  "color": "outline"
}
```

| Property | Type | Notes |
|---|---|---|
| `thickness` | number | Default `1` |
| `color` | string | Theme color or hex |

Use Divider sparingly to separate groups inside a Column or Card.
