# AudioPlayer

```json
{
  "id": "clip",
  "component": "AudioPlayer",
  "url": "https://example.com/clip.mp3",
  "title": "Interview clip"
}
```

| Property | Type | Notes |
|---|---|---|
| `url` | string | Audio URL or registered storage path |
| `title` | string | Optional label |

Use AudioPlayer for short listenable content. Keep the title meaningful.
