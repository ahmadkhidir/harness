# Video

```json
{
  "id": "demo_video",
  "component": "Video",
  "url": "https://example.com/demo.mp4",
  "autoPlay": false,
  "controls": true
}
```

| Property | Type | Notes |
|---|---|---|
| `url` | string | Video URL |
| `autoPlay` | boolean | Default `false` |
| `controls` | boolean | Default `true` |

Use Video only when motion is part of the answer. Prefer a link when inline playback is unnecessary.
