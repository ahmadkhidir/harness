# Column

```json
{
  "id": "body",
  "component": "Column",
  "children": ["title_text", "details_text", "action_btn"],
  "spacing": 12,
  "alignment": "stretch"
}
```

| Property | Type | Notes |
|---|---|---|
| `children` | list of component IDs | Vertical order |
| `spacing` | number | Default `8` |
| `alignment` | string | `start`, `center`, `end`, `stretch` |

Column is the default layout container for cards and pages.
